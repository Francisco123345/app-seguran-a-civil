GuardaCidadã

Portal de Segurança, Prevenção e Colaboração Comunitária

📌 Sobre o Projeto

O GuardaCidadã é uma solução digital criada para engajar moradores e comunidades locais na prevenção de incidentes e na melhoria da segurança pública local. A plataforma permite reportar ocorrências, visualizar manchas de calor de incidentes, acionar redes de apoio da vizinhança e acessar rapidamente números e guias de emergência.

🎯 Objetivos

Prevenção Ativa: Prover dados visuais claros para auxiliar na tomada de decisões comunitárias e individuais.

Engajamento Comunitário: Fortalecer o conceito de "Vizinhança Solidária" através da cooperação contínua.

Resposta Rápida: Oferecer ferramentas ágeis de alerta e utilidade pública em situações de vulnerabilidade.

✨ Funcionalidades Principais

🚨 Registro & Mapeamento de Ocorrências

Cadastro simplificado de incidentes (assaltos, iluminação precária, suspeita, furtos).

Visualização em mapa interativo com marcadores categorizados e mapas de calor (heatmaps).

🔔 Alertas de Emergência & Botão de Pânico

Disparo de alertas imediatos para vizinhos cadastrados e contatos de emergência.

Notificações de área de risco em tempo real.

📊 Painel Analítico e Estatísticas

Métricas de incidentes por bairro, tipo e período horário.

Indicadores de resolução e relatórios comunitários exportáveis.

🤝 Rede de Vizinha Solidária

Grupos de apoio por rua/bairro.

Canal direto para avisos comunitários e comunicados internos.

📖 Central de Ajuda e Telefones Úteis

Acesso rápido aos números da Polícia Militar (190), SAMU (192), Bombeiros (193), Central da Mulher (180), entre outros.

Guias preventivos de conduta para situações de emergência.

🚀 Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias modernas voltadas para alto desempenho e facilidade de manutenção:

Frontend:

HTML5 / CSS3 (Design Responsivo e Moderno)

Tailwind CSS - Utility-first CSS Framework

JavaScript (ES6+) - Lógica dinâmica e interatividade

FontAwesome / Lucide Icons - Ícones intuitivos

Mapas e Visualização:

Leaflet.js ou Google Maps API para geolocalização e renderização do mapa.

Ferramentas de Suporte:

Git & GitHub para versionamento de código.
